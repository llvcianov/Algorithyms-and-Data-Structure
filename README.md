# Algorithms and Data Structures — Homework

Homework assignments for the **Algorithms and Data Structures** course (Prof. Roberto Pietrantuono), Master's Degree in Computer Engineering, University of Naples Federico II — A.Y. 2024/2025.

Submitted together with a course mate (Russo); most of the work on both homework sets was my own.

## Homework 1

Assignment: [`Homework1/Homework set 1.pdf`](Homework1/Homework%20set%201.pdf) · Report: [`Homework1/HW1_RussoVitale.pdf`](Homework1/HW1_RussoVitale.pdf)

- **[`Problema1/`](Homework1/Problema1/)** — find the maximum of a unimodal array in O(log n), using a modified binary search.
- **[`Problema2/`](Homework1/Problema2/)** — divide-and-conquer algorithm to find the longest common prefix of a set of strings.
- **[`Problema3/`](Homework1/Problema3/)** — `TREAP-INSERT`: insertion into a treap (a binary search tree ordered by key, with randomized priorities maintaining the min-heap property, used to keep the tree balanced in expectation).
