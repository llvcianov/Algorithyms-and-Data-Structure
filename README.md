# Algorithms and Data Structures — Homework

Homework assignments for the **Algorithms and Data Structures** course (Prof. Roberto Pietrantuono), Master's Degree in Computer Engineering, University of Naples Federico II — A.Y. 2024/2025.

Submitted together with a course mate (Russo).

## Homework 1

Assignment: [`Homework1/Homework set 1.pdf`](Homework1/Homework%20set%201.pdf) · Report: [`Homework1/HW1_RussoVitale.pdf`](Homework1/HW1_RussoVitale.pdf)

- **[`Problema1.cpp`](Homework1/Problema1.cpp)** — find the maximum of a unimodal array in O(log n), using a modified binary search.
- **[`Problema2.cpp`](Homework1/Problema2.cpp)** — divide-and-conquer algorithm to find the longest common prefix of a set of strings.
- **[`Problema3.cpp`](Homework1/Problema3.cpp)** — `TREAP-INSERT`: insertion into a treap (a binary search tree ordered by key, with randomized priorities maintaining the min-heap property, used to keep the tree balanced in expectation).

## Homework 2

## Esercizi

Smaller standalone exercises, grouped by technique. Each folder has its solution alongside its assignment text where one was available — a couple don't have one (lost or never saved); for those, the folder has a short `README.md` instead reconstructing what the code solves.

**[`BackTracking/`](Esercizi/BackTracking)**
- [`Disposizioni`](Esercizi/BackTracking/Disposizioni) — generate all permutations of a set of N values.
- [`FindWordInMatrix`](Esercizi/BackTracking/FindWordInMatrix) — find a word in a letter grid, moving between adjacent cells.
- [`HammingDistance`](Esercizi/BackTracking/HammingDistance) — Hamming-distance-based exercise.
- [`IntercorsoBackTracking`](Esercizi/BackTracking/IntercorsoBackTracking) — mid-term backtracking exercise.
- [`Labirinto`](Esercizi/BackTracking/Labirinto) — maze pathfinding.
- [`XORSum`](Esercizi/BackTracking/XORSum) — XOR-sum backtracking exercise.

**[`DivideEtImpera/`](Esercizi/DivideEtImpera)**
- [`2elementSum`](Esercizi/DivideEtImpera/2elementSum) — find a pair of elements in an array summing to a target value.
- [`IntercorsoDI`](Esercizi/DivideEtImpera/IntercorsoDI) — mid-term divide-and-conquer exercise.
- [`MInDifferenceMatrix`](Esercizi/DivideEtImpera/MInDifferenceMatrix) — minimum-difference matrix exercise.
- [`Scrumble`](Esercizi/DivideEtImpera/Scrumble) — "Scramble String": decide if one string is a scrambled version of another.
- [`aritmeticProgression`](Esercizi/DivideEtImpera/aritmeticProgression) — arithmetic-progression exercise.
- [`droppingBalls`](Esercizi/DivideEtImpera/droppingBalls) — dropping-balls exercise.

**[`ProgrammazioneDinamica/`](Esercizi/ProgrammazioneDinamica)**
- [`espressione`](Esercizi/ProgrammazioneDinamica/espressione) — max/min value obtainable by placing parentheses in a +/× expression.
- [`ladri`](Esercizi/ProgrammazioneDinamica/ladri) — split a hoard of coins between two thieves minimizing the difference between their shares.
- [`militari`](Esercizi/ProgrammazioneDinamica/militari) — maximum number of non-crossing communication links between two rows of military bases.
- [`palindromi`](Esercizi/ProgrammazioneDinamica/palindromi) — longest palindromic subsequence of a string.
- [`prodotti`](Esercizi/ProgrammazioneDinamica/prodotti) — pick at most one product per category to maximize spend within a budget.
- [`travi`](Esercizi/ProgrammazioneDinamica/travi) — minimum-cost ordered cutting of a beam.
